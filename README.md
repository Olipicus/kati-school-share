# web-share/ — เวอร์ชันแชร์ของเว็บเปรียบเทียบโรงเรียน

สำเนาเว็บสำหรับ**แชร์ให้ผู้ปกครองคนอื่น** — ข้อมูลโรงเรียนเดียวกับ `web/` หลักทุกประการ (สร้างจาก wiki/ ตัวเดียวกัน) แต่**ไม่มีข้อมูลส่วนตัวของเจ้าของโปรเจกต์**:

- **ไม่มีข้อมูลบ้าน/ที่ทำงาน** — ไม่มีพิกัด ชื่อ ระยะ TDP/One Bangkok เส้นทางจากบ้าน และ next actions/criteria/log (to-do ส่วนตัว)
- **จุดตั้งต้นของระยะทางทั้งหมด = โรงเรียนอนุบาลบ้านสนุกคิด (เขตสะพานสูง)** — ผู้รับแชร์ลากหมุด 🏫 ในแท็บแผนที่ไปที่บ้านตัวเองได้ เว็บจะคำนวณเส้นทางขับรถใหม่ผ่าน OSRM (ต้องออนไลน์)
- localStorage แยกชุด (`katis.*`) จากเวอร์ชันหลัก — เปิดสองเวอร์ชันในเบราว์เซอร์เดียวกันไม่หยุกหยิมกัน

## วิธีสร้างใหม่ (หลังแก้ wiki/)

```bash
python3 web/build_share.py
```

สคริปต์อ่าน wiki/ + raw/ เอง (ไม่ต้องรัน web/build.py ก่อน) → เขียน `data.js`, `route-cache.json`, `assets/` และคัดลอก `index.html`/`style.css`/`app.js` จาก `web/` (ใช้ไฟล์เดียวกัน แยกพฤติกรรมด้วย flag `D.share` ใน data.js)

**privacy verifier**: build จะตรวจว่าไม่มีข้อมูลบ้าน/ที่ทำงาน (ชื่อ พิกัด วลีต้องห้ามชุดหนึ่ง) หลงเหลือใน data.js — ถ้าเจอจะ **fail และไม่ควรเอาไฟล์ไปแชร์** ให้เพิ่มกฎใน `scrub()` ของ build_share.py แล้วรันใหม่ (wiki ที่เขียนใหม่อาจใช้วลีที่กฎยังไม่ครอบ)

## วิธีแชร์

โฟลเดอร์นี้ self-contained (~98MB ส่วนใหญ่คือโบรชัวร์/เอกสารสแกน 27 ไฟล์):

- **zip ทั้งโฟลเดอร์ส่งให้** — ผู้รับแตกไฟล์แล้วเปิด `index.html` (แท็บแผนที่/ปุ่ม zip โบรชัวร์ต้องออนไลน์ ส่วนอื่นใช้ได้ offline)
- หรือ deploy ขึ้น static host ก็ได้ (GitHub Pages ฯลฯ) — serve ที่ root ของโฟลเดอร์นี้
